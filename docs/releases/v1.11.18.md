# v1.11.18 — 2026-10-24

## Shop

- shop moved into a deterministic skill tree (`shop-*` nodes, `lib/shop`), the
  project keeps no shop script;
- robots are published without a price: the page shows the robot and «Заказать»,
  the price stays in `data/<host>/prices.yaml` and is given on the phone;
- `products/catalog.json` is price-free, tags are assigned by
  `products/tag-rules.yaml`, brands come from `data/<host>/sellers.yaml`;
- prices removed from the UI (`ProductPrice`, `priceLabel`, JSON-LD `offers`);
- `/add-products` raises `content-shop-filler`, then `content-shop-optimizer`.

# hellorobot

## Архитектура

- Фронтенд: Astro (гибридный режим — SSG для новостей, SSR для магазина).
- Бэкенд: WordPress + WooCommerce + WPGraphQL + WPGraphQL WooCommerce (WooGraphQL).
- Интерактивные острова: React/Vue/Svelte — только для корзины, калькуляторов и кнопок покупки.

## Страницы

- Главная — новостная (WordPress).
- Страница с описанием технологии робототехники.
- Отдельная страница интернет-магазина (WooCommerce).
- Новости — на WordPress.
